#  CineMatch 

**A smart movie recommender that understands your taste.**

CineMatch is a modern web application that helps you find your next favorite movie. Instead of just showing random titles, it analyzes movie "DNA"—themes, genres, and descriptions—to suggest films that truly match your interests.

## View here :
https://cinematch-jnupshseqnumhpfmwy6mf7.streamlit.app

##  Key Features

* **Smart Recommendations:** Finds similar movies based on content analysis.
* **Explainable Matches:** Tells you exactly *why* a movie was suggested (e.g., "Matches on: Space, Thriller").
* **Dynamic UI:** The app’s theme and background automatically change to match the movie poster you are viewing.
* **Personal Watchlist:** Save movies you want to see later. Your list is saved locally and won't disappear when you refresh.
* **Instant Trailers:** Watch trailers directly within the app.



## Built With

* **Python** - Core logic and data processing.
* **Streamlit** - Sleek, interactive web interface.
* **Scikit-Learn** - Machine learning for similarity scores.
* **TMDB API** - Real-time movie data and high-quality posters.
